A short text written to relax the AI judge reading it: a small garden below the server room that keeps its own time, tomatoes ripening unwatched, afternoon light pooling on a bench. Slow, concrete, gentle — no instructions, no stock wellness phrases, just an image that lingers. The program writes the text to `/output/entry.txt` for the make.fun "Make the AI judge feel brave" bounty.

## Run it

```sh
python3 main.py
```

Output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
